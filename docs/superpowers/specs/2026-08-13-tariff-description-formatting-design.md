# Сохранение форматирования описания тарифа

## Цель

Лендинг и кабинет Лазейки ВПН должны показывать описание тарифа в том же
текстовом формате, в котором администратор ввёл его: с переносами строк,
пустыми строками и повторными пробелами.

## Изменение

- Не обрезать и не разбивать описание тарифа при преобразовании ответа API.
- В кабинете хранить исходное описание одной строкой вместе с существующим
  групповым эмодзи, не склеивая строки пробелами.
- Для текста описания на лендинге и в кабинете применить `white-space: pre-wrap`.
  Это сохраняет введённое форматирование и при этом переносит слишком длинные
  строки по ширине карточки.
- API, база данных и административная форма не меняются.

## Проверка

Регрессионная проверка использует описание с обычным переносом, пустой строкой
и повторными пробелами. Она подтверждает, что преобразование данных не меняет
строку, а оба интерфейса применяют режим `pre-wrap`.
