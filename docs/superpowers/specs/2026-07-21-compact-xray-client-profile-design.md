# Компактный Xray-профиль Remnawave

## Цель

Заменить текущий профиль на автономный JSON без многотысячных списков доменов. Российские сервисы из короткого списка идут напрямую, остальной трафик — через VPN.

## Маршрутизация

Порядок правил:

1. BitTorrent блокируется.
2. Локальные и служебные IP-диапазоны идут через `direct`.
3. Доменные суффиксы основных российских сервисов идут через `direct`: VK, Mail.ru, OK, Госуслуги, ФНС, Ozon, Wildberries, Яндекс, Дзен, Avito, 2GIS, Mos.ru и основные банки.
4. Остальной TCP/UDP-трафик идёт через `auto-wl`, который выбирает VPN-ноды `eu-*` и использует WL-пул как fallback.

## Проверка WL

Remnawave продолжает создавать outbound’ы `wl-*` из текущих UUID. `burstObservatory` проверяет их через `https://connectivitycheck.gstatic.com/generate_204`, а `whitelist-balancer` со стратегией `leastLoad` выбирает доступный WL с минимальной задержкой. Неработающие или слишком медленные WL не выбираются; если один сервер отпал, используется следующий живой.

## DNS

Используются два DoH: Яндекс как основной и Google как резервный. Отдельный многотысячный DNS-список удаляется; маршрутизацию определяют компактные правила `routing`.

## Совместимость и проверка

Сохраняются текущие Remnawave `injectHosts`, loopback fallback, локальные SOCKS/HTTP inbounds и существующие теги. Готовый файл проверяется стандартным JSON-парсером и сравнением обязательных тегов и UUID с исходником.
