# Публичная страница подписки на React

## Цель

Перевести браузерное представление `/api/sub/:token` на React и дизайн-систему кабинета, не меняя этот URL и ответы для VPN-клиентов.

## Маршруты и данные

- `GET /api/sub/:token` сохраняет текущую проверку браузера по `Accept` и `User-Agent`.
- VPN-клиенты продолжают получать объединённую конфигурацию по существующей логике.
- Браузеру маршрут отдаёт существующий SPA-шаблон через `renderSpaIndex`; перед этим токен проверяется, чтобы неизвестная подписка по-прежнему возвращала `404`.
- Новый публичный `GET /api/public/subscription-page/:token` возвращает только уже публичные данные страницы: бренд, URL подписки, срок и статусы, квоты компонентов, доступные пользователю локации и конфигурацию гайдов.
- Сбор модели остаётся на бэкенде. Доступные локации фильтруются пересечением нод хоста с нодами сквадов компонентов подписки.
- Ответы страницы и JSON помечаются `private, no-store`; токен не записывается в логи клиента.

## React-страница

- В `App.tsx` добавляется публичный маршрут `/api/sub/:publicSubscriptionToken`, не требующий авторизации кабинета.
- Новый экран использует существующие компоненты и токены: `Card`, `Button`, `Dialog`, `QRCodeSVG`, Lucide, общую тему и фон приложения.
- Порядок блоков:
  1. Шапка с логотипом, брендом и общим статусом.
  2. Сетка из карточки `WhiteList` с progress bar и карточки `Основной доступ` без progress bar. На узком экране — одна колонка.
  3. Стеклянная карточка `Ваша подписка` со ссылкой, копированием, рабочим QR и быстрыми кнопками Happ/INCY.
  4. `Гайд по подключению` с автоматически выбранным устройством, пикером платформы, вкладками и карточками приложений.
  5. Сворачиваемый список доступных локаций и предупреждение не передавать ссылку.
- Быстрая кнопка использует существующий deeplink. Если браузер не покинул страницу, через короткую задержку выбирается соответствующее приложение и выполняется плавный скролл к гайду.
- QR строится существующей зависимостью `qrcode.react`; новые зависимости не добавляются.

## Состояния

- Загрузка: скелетоны в геометрии основных карточек.
- Недействительный токен: компактное состояние `Подписка не найдена`.
- Временная ошибка Remnawave: SPA остаётся доступной и показывает повторяемую ошибку с кнопкой `Повторить`.
- Пустые гайды или локации используют текущие поясняющие состояния без выдуманных данных.

## Проверка и публикация

- Бэкенд-тест проверяет разделение browser/VPN-ответов, безопасную публичную модель и фильтр локаций.
- Фронтенд проходит production build.
- В браузере проверяются desktop и mobile, QR, копирование, смена устройства/приложения и fallback-скролл.
- Перед загрузкой файлов на сервер создаётся новый архивный бэкап production-каталога.
- После сборки проверяются healthcheck API, кабинет и браузерный `/api/sub/:token`; VPN-запрос с небраузерным `User-Agent` не должен получать HTML.

## Вне объёма

- Авторизация публичной страницы.
- Изменение формата VPN-конфигурации или логики объединения компонентов.
- Новый редактор гайдов или новая UI-библиотека.
