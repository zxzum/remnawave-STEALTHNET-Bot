# Лазейка ВПН 6.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перенести безопасную часть STEALTHNET 6.1.1, добавить выключенный по умолчанию RollyPay и opt-in дизайн Aurora без изменения текущего поведения Лазейка ВПН.

**Architecture:** Upstream не сливается целиком. Исправления адаптируются к текущим общим сервисам; RollyPay подключается через существующие Payment/SystemSetting и `markPaymentPaid`; Aurora выбирается чистой функцией с fallback на текущий кабинет и использует существующие API/context.

**Tech Stack:** TypeScript, Express, Prisma, React 18, React Router, Vite, Node test runner, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-08-23-upstream-6.1.1-aurora-rollypay-design.md`

## Global Constraints

- Продукт называется «Лазейка ВПН»; `stealthnet` сохраняется только в compatibility identifiers.
- Текущий кабинет и существующие платёжные провайдеры остаются default.
- `aurora` и `rollypay` должны быть выключены по умолчанию.
- Никаких миграций production-БД; при необходимости схема проверяется только на временной БД.
- Не заменять локальные subscription lifecycle, conversion, auto-renew, link rotation, squad traffic и trial lock upstream-версиями.
