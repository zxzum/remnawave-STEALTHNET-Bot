# План реализации

1. Исправить все пути отправки баннеров: бот скачивает картинку с backend и передаёт Telegram `InputFile`, а не внешний URL.
2. Добавить общий репортинг ошибок Telegram API и backend-эндпоинт для безопасной доставки событий в группу уведомлений.
3. Добавить расчёт предпросмотра объединения аккаунтов: trial, одинаковые тарифы, конвертация разных тарифов и безопасные ограничения для двух полноценных аккаунтов.
4. Перевести Mini App и bot flow на `preview -> confirm`; сделать подтверждение идемпотентным и проверить привязку после транзакции.
5. Написать узкие unit-тесты для политики объединения, форматирования ошибки и запрета передачи баннера внешним URL.
6. Запустить тесты и сборки backend/bot/frontend, проверить diff, создать commit и выполнить `git push` текущей ветки.
